# Outputs

Generated artifacts from every OS command. Organized by type. Dated. Never deleted.

## Folder Map

| Folder | What goes here | Naming convention |
|---|---|---|
| `roasts/` | Profile roasts, proposal roasts | `YYYY-MM-DD-profile-roast.md` / `YYYY-MM-DD-proposal-SLUG.md` |
| `proposals/` | Final written proposals, ready to send | `YYYY-MM-DD-SLUG.md` |
| `intel/` | Job intel briefs, client profiles | `YYYY-MM-DD-job-SLUG.md` / `YYYY-MM-DD-client-SLUG.md` |
| `strategy/` | Weekly reviews, niche radar reports | `YYYY-MM-DD-strategy-review.md` / `YYYY-MM-DD-niche-NICHE.md` |
| `briefs/` | Daily briefs | `YYYY-MM-DD-daily-brief.md` |

## Rule

Every command that generates output writes here AND appends a summary to the brain.
- This folder = human-readable artifact (full content, easy to find later)
- Brain = structured memory node (frontmatter, relationships, pattern tracking)

Never edit files after they're created — append only. Outcomes get added at the bottom.
