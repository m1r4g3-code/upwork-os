## Workflow List (Phase 1)

### 1. Topic Generator (daily trigger, 6am)
- Polls News API for trending topics
- Sends to GPT-4: generate topic + caption + hook for each platform type
- Writes rows to Content Queue (status: ready)

### 2. HeyGen Workflow (triggers on rows with content_type: reel)
- Reads next `ready` reel row → sets `locked`
- Sends to HeyGen API with Avatar ID + Voice ID
- Polls HeyGen status until complete
- Downloads video → saves to Drive
- Updates row: drive_file_id, heygen_video_id, status: ready_to_post

### 3. Image Generator (triggers on rows with content_type: photo)
- LinkedIn rows → Flux Pro via Replicate API
- Facebook/Instagram rows → DALL-E 3 via OpenAI API
- Saves to Drive, updates row status

### 4. Publisher — TikTok
- Polls queue for ready reel rows targeted at TikTok
- Checks daily counter (respects TikTok limits)
- Sets row locked → posts via TikTok Content Posting API → updates done/failed

### 5. Publisher — LinkedIn
- Photo posts: Graph API media upload + publish
- Carousel: triggers at post_counter = 6 (fetches from carousel source)

### 6. Publisher — Facebook + Instagram
- Reels + photos via Meta Graph API
- Carousel: triggers at post_counter = 3 (shared GPT carousel content)

### 7. Publisher — YouTube
- Shorts only (Phase 1): reuses HeyGen reel files
- YouTube Data API v3 upload with auto-title + description from Sheets

### 8. Error Handler (runs after each publish attempt)
- On failure: increment attempt_count
- attempt_count = 1: retry in 2 min
- attempt_count = 2: retry in 8 min
- attempt_count = 3: set failed_alert, send Telegram notification

### 9. Daily Summary (9pm trigger)
- Counts rows by status for the day
- Sends Telegram: "Today: 7 posts sent, 0 failed" (or lists failures)

## Phase 1 — Reliable Core

**Goal:** Daily posting machine runs without babysitting. Everything connects to Sheets. No overengineering.

**In scope:**
- Full Sheets CMS schema (3 tabs)
- HeyGen workflow update (Sheets input, Drive output)
- Image generation workflows (Flux Pro + DALL-E)
- Publisher workflows for all 5 channels
- Queue collision prevention (locked row pattern)
- Rate limit handling (daily counters per platform)
- Exponential backoff retry (3 attempts max)
- Telegram monitoring (daily summary + error alerts)
- Carousel counter logic (per platform schedule)
- Google Sheets + HeyGen + n8n credentials setup

**Out of scope (Phase 1):**
- Approval/review toggle
- Analytics dashboard
- Long-form YouTube
- Multi-avatar support
- Content performance feedback loop

**Timeline:** 3 weeks

| Week | Deliverables |
|---|---|
| Week 1 | Sheets schema setup + HeyGen workflow adaptation + Drive integration |
| Week 2 | Content generator + all 5 publisher nodes live |
| Week 3 | Error handling + queue logic + cross-platform testing + handoff |

**Milestone checkpoints:**
- End of Week 1: HeyGen generates a video from a Sheets row and saves to Drive
- End of Week 2: All 5 channels post successfully from the queue (manual trigger)
- End of Week 3: Fully automated run completes with no manual input, daily summary fires to Telegram
